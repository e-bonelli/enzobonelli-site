Air-gapped multi-agent system for tax & financial data

In production, 2025–2026

Tax and financial records are full of personal data, and the answers drawn from them have to be defensible. This system keeps every document inside an isolated environment, organizes it into a Neo4j knowledge graph, and lets a five-agent system reason over that graph — so every output arrives with the lineage behind it.

  1. Step 1 of 5 · The boundary

    Nothing leaves the environment.

    Every service runs inside an air-gapped boundary. Sensitive records, PII included, are processed where they live, with no connection to the outside.

    • Air-gapped
    • Docker
    • PII

  2. Step 2 of 5 · Ingest

    Documents enter through ingestion services.

    Dockerized FastAPI microservices take in tax and financial records and load them into the knowledge graph.

    • FastAPI
    • Python
    • Docker

  3. Step 3 of 5 · Build the graph

    Records become a connected knowledge graph.

    The data is stored in Neo4j as connected entities, so each fact stays linked to where it came from. That lineage is what makes the reasoning traceable later.

    • Neo4j
    • GraphRAG
    • Lineage

  4. Step 4 of 5 · Agents query the graph

    Five agents reason over the graph.

    A five-agent architecture works through the records, querying the graph for context and citing it for the conclusions it draws.

    • Multi-agent
    • GraphRAG
    • FastAPI

  5. Step 5 of 5 · Explainable answer

    Every answer shows its work.

    The agents deliver their output to a vanilla JS interface, where each answer can be traced back through the graph to the records behind it.

    • Explainable output
    • Vanilla JS
    • Lineage

  6. Complete · The full system

    Isolated, traceable, explainable.

    Sensitive financial data stays inside the boundary, and every output can be followed back to its source. GraphRAG on Neo4j gives reviewers the reasoning, not just the result.

    • Multi-agent
    • GraphRAG
    • Neo4j
    • FastAPI
    • Docker
    • Python
    • Vanilla JS
