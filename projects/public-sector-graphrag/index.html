Agentic GraphRAG for air-gapped LLM capability

Public sector

An agentic RAG and GraphRAG architecture that brings LLM capability into accredited government networks (IL4+) that are fully air-gapped, built on a knowledge-service data model. The AI lead role covered directing the team that built that data model and the AI integration into existing infrastructure.

  1. Step 1 of 5 · The secure network

    Everything stays inside the network.

    Everything runs inside an accredited government network (IL4+) that is fully air-gapped.

    • IL4+
    • Air-gapped

  2. Step 2 of 5 · Knowledge-service data model

    A knowledge graph grounds the answers.

    The AI lead role covered directing the team that built the knowledge-service data model: a Neo4j knowledge graph that grounds the agents’ answers.

    • Neo4j
    • GraphRAG
    • Data model

  3. Step 3 of 5 · Agent crew

    Agents retrieve context from the graph.

    Agents built with CrewAI and LangChain retrieve context from the graph, combining agentic RAG with GraphRAG.

    • CrewAI
    • LangChain
    • Agentic RAG

  4. Step 4 of 5 · Air-gapped LLM

    The model runs inside the boundary.

    The agents reason with an LLM that runs inside the boundary and calls no external model APIs.

    • Air-gapped LLM
    • No external APIs

  5. Step 5 of 5 · Served on the network

    Answers are served on the network.

    A FastAPI service in Docker, shipped with GitLab CI, delivers answers on the network and integrates with existing infrastructure. An enterprise API was also ported from Python to Go for a more scalable, resource-efficient service.

    • FastAPI
    • Docker
    • GitLab
    • Go

  6. Complete · The full system

    Agentic GraphRAG, entirely inside the boundary.

    Agentic RAG and GraphRAG on a knowledge-service data model bring LLM capability into accredited government networks (IL4+), with no external model APIs and integrated with existing infrastructure.

    • GraphRAG
    • CrewAI
    • LangChain
    • Neo4j
    • FastAPI
    • Go
